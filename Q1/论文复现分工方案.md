## 第一部分 · 论文第一问拆解

### 1.1 核心问题：一句话到五层

原始问题：「清明时节雨纷纷 —— 2026 年这 7 个城市会雨纷纷吗」。拆成可计算的问题需要五层：

| 层级 | 要解决的问题 | 论文的做法 | 复现要点 |
|---|---|---|---|
| **定义层** | 「雨纷纷」怎么量化？ | 日降雨量 0.1–9.9 mm **且** 降雨持续 ≥ 3 h（依据 GB/T 28592—2012 小雨等级） | 阈值区间来自国标，**时长 3 h 是论文自设的**，要自己论证 |
| **预测层** | 2026 年 4/4–4/6 的降雨量、降雨时长是多少？ | 每城每项一条时间序列（20 个点），ARIMA(p,d,q) 外推 | 7 城 × 2 项 = 14 条序列 |
| **判定层** | 按判据，哪些城市算「雨纷纷」？ | 查表 5-1，逐城给是/否 | **口径必须先定**（单日制？假期制？），否则结论不可比 |
| **检验层** | 模型靠不靠谱？ | 2006–2025 按 7:3 划分，算 RMSE / MAE，画对比折线 | 时序不能随机划分，必须按时间顺序切 |
| **修正层** | 怎么用最新实况修正？ | 改成 1:1 划分 + 「增加训练轮次」 | 题目**硬性要求**，论文答得弱，你们可以做得比原文好 |

### 1.2 方法框架（论文的实际技术路线）

```
数据获取(NOAA GSOD, 2006–2025, 4/4–4/6)
        │
        ▼
缺失值处理（历年同期非缺测均值填补）
        │
        ▼
按城市拆成两条序列 ── 降雨量序列 ┐
                    └ 降雨时长序列 ┘
        │
        ▼
ADF 单位根检验（H0: 非平稳）
        │  不平稳 → 差分（d+1）→ 复检
        ▼
LB 白噪声检验（H0: 白噪声）
        │  非白噪声才可建模（白噪声 = 没有可提取的信息）
        ▼
ACF / PACF 图 → 定阶 p、q
        │
        ▼
ARIMA(p,d,q) 参数估计
        │
        ▼
2026/4/4–4/6 预测（每城 3 天 × 2 项 = 42 个数）
        │
        ▼
按「雨纷纷」判据逐城判定 → 结论
        │
        ▼
合理性检验（训练/测试划分 → RMSE、MAE → 对比折线图）
        │
        ▼
模型修正（滚动重估 / 实况加权）
```

### 1.5 复现必查的 6 个坑（**动手前先看这段**）

1. **⚠️ 论文表 5-1 的判定与它自己定的阈值矛盾（最重要）。**
   按「0.1–9.9 mm 且时长 ≥3 h、假期三日中至少一日满足」重算表 5-1：
   - 满足：**西安**（9.85 mm / 3.97 h）、**洛阳**（8.89、5.73）、**吐鲁番**（9.36、8.34）、**婺源**（8.10、8.92）
   - 不满足：**武汉**（12.25 / 10.65 / 11.22，全部 > 9.9）、**杭州**、**毕节**
   - 论文结论却是「西安、洛阳、吐鲁番、**武汉**」——**「婺源」与「武汉」疑似互换**；且表里 10.05、12.25 这类 >9.9 的数值被称"标红满足"。
   → 复现时**必须如实记录**并给出按定义重算的结果。这是你们这份复现最有价值的差异化内容。
2. **序列几乎全零，RMSE 没有说服力。** 附录里西安 20 年 4/4 降水量是 `0.058889, 0, 0.13, 0, 0, 0, 0, 0.27, ...`，绝大多数为 0。RMSE ≈ 0.05–0.20 mm 意味着「一律预测 0」也能达到。**必须加基线对比**，否则「精度高」是假的。
3. **20 个样本做 ARIMA 偏少。** 定阶会不稳。给出阶数搜索范围（0–2）+ AIC 表，报告一组敏感性即可，不要展开长篇。
4. **口径混用。** 论文 5.2.2 把三天拼成 60 点做 ADF，5.3 又按单序列预测，两处样本定义不一致。复现统一写成「每城每年一个观测，n=20」并说明理由。
5. **「增加训练轮次」不是 ARIMA 的概念**（那是深度学习），5.4.2 实际只改了划分比例；且 1:1 后测试集变小、误差变小**不能证明模型变好**。三天版直接不复现这个 1:1，改用「留出 2025」做真外推 + 滚动重估做修正。
6. **表号/图号错乱**（表 5-3 标题下写表 5-4、图 6-1 重复编号）。按内容引用，不照抄编号。
